# 나에게 맞는 정신건강전문요원 찾기

정신건강전문요원 네 직역의 역할을 쉽고 친근하게 이해하고, 몇 가지 질문을 통해 현재 자신의 필요와 가까운 전문요원을 살펴볼 수 있도록 제작한 교육·홍보용 웹게임입니다.

현재 잠정 Final 버전은 `1.1.0`입니다.

## 제작 정보

- 기획: 이혜현
- 제작: 유튜브 **심리실언니들**  
  [채널 바로가기](https://youtube.com/channel/UC66vhhTaUHt4p-fH-bbN8qw?si=WAW6P0TEOHRbbMVm)
- 감수·배포: **한국임상심리전문가협회**  
  [협회 홈페이지](https://kocpa.kr/)

## 제작 의도

정신건강전문요원은 보건복지부 국가자격을 취득한 전문인력으로, 서로 협력하면서 각기 다른 역할을 담당합니다.

- 정신건강임상심리사: 심리평가, 심리상담 및 심리치료
- 정신건강간호사: 증상 관찰, 건강관리 및 치료 지원
- 정신건강사회복지사: 복지서비스와 지역사회 자원 연계
- 정신건강작업치료사: 일상생활, 작업 수행 및 사회참여 회복 지원

이 프로젝트는 네 직역의 차이를 경쟁이나 우열로 설명하지 않습니다. 사용자가 자신의 현재 필요를 돌아보고 적절한 전문가와 서비스를 이해하는 출발점을 제공하는 것이 목적입니다.

## 중요 안내

이 웹게임은 교육·홍보를 위한 정보 제공 도구이며 의료적 진단, 심리검사, 치료 또는 전문적인 상담을 대신하지 않습니다.

자해·타해 위험, 현실 판단의 어려움, 극심한 증상 악화 등 위기 상황에서는 게임 결과보다 즉각적인 안전 확보가 우선입니다. 가까운 응급실이나 정신건강의학과, 자살예방상담전화 109 또는 112 등 즉각적인 도움을 이용하세요.

## 자산 및 권리

본 프로젝트에 포함된 기획 내용, 문구, 디자인, 캐릭터 이미지, 결과 카드와 기타 시각 자산은 **한국임상심리전문가협회의 자산으로 관리됩니다.**

별도의 명시적 허가 없이 다음 행위를 하지 마세요.

- 프로젝트 또는 포함 자산의 무단 복제·재배포
- 캐릭터, 로고, 협회명 또는 결과 카드의 임의 변경
- 상업적 이용이나 제3자 서비스로의 전용
- 출처·크레딧·안전 안내 문구의 삭제 또는 변형

수정·재배포·외부 활용이 필요한 경우 한국임상심리전문가협회와 사전에 협의하세요. 이 저장소에 별도의 오픈소스 라이선스가 명시되지 않은 한 임의 사용 권한이 부여되는 것은 아닙니다.

## 기술 구성

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages
- Google Apps Script + Google Sheets 익명 통계
- Kakao JavaScript SDK
- html2canvas

별도의 프레임워크나 빌드 과정 없이 정적 파일로 배포됩니다.

## 주요 파일

```text
index.html              화면 구조와 외부 스크립트 연결
style.css               게임 화면과 모바일 UI
script.js               질문 흐름, 점수 계산, 장면 전환, 결과 표시
analytics.js            익명 방문·완료·공유 분석
share-card.js           결과 공유 카드 생성
share-card.css          결과 공유 카드 스타일
google-apps-script.gs   Google Sheets 수집 및 Dashboard
ANALYTICS_SETUP.md      통계 시스템 설정·배포 안내
assets/                 캐릭터, 배경, 결과 및 공유 이미지
data/                   알고리즘 참고 데이터
```

## 로컬 실행

브라우저의 파일 열기보다 간단한 로컬 웹서버 사용을 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`으로 접속합니다.

## 배포

GitHub Pages가 사용하는 브랜치의 프로젝트 루트에 정적 파일을 업로드합니다. 배포 후 GitHub Actions의 `pages build and deployment`가 성공했는지 확인하세요.

Apps Script를 수정한 경우에는 코드 저장만으로 Web App에 반영되지 않습니다.

1. **배포 → 배포 관리**
2. 기존 Web App 배포 수정
3. **새 버전** 선택
4. 다시 배포

기존 배포를 수정하면 일반적으로 `/exec` Web App URL은 유지됩니다.

## 익명 통계와 개인정보

분석 시스템은 이름, 이메일, 현재 URL, 브라우저 정보 등의 개인정보를 Google Sheets에 저장하지 않습니다.

- 무작위 익명 방문자 ID
- 30분 기준 익명 세션 ID
- 개별 플레이 ID
- 방문·완료·공유 이벤트
- 게임 버전, 결과 조합, 점수와 패턴

브라우저 저장소를 삭제하거나 다른 브라우저·기기를 사용하면 새로운 방문자로 인식될 수 있습니다. 자세한 설정과 집계 기준은 `ANALYTICS_SETUP.md`를 참고하세요.

## 수정 시 반드시 확인할 사항

### 1. 결과 알고리즘

`script.js`의 질문별 점수, 직역 키와 결과 판정 로직은 검토 없이 변경하지 마세요.

공통 직역 키는 다음과 같습니다.

```text
clinical     정신건강임상심리사
nurse        정신건강간호사
social       정신건강사회복지사
ot           정신건강작업치료사(게임 내부 키)
occupational 분석 데이터의 작업치료사 키
```

`ot`와 `occupational`의 변환을 제거하거나 혼용하면 통계와 결과 공유 기능이 어긋날 수 있습니다.

### 2. 버전 관리

사용자에게 공개되는 질문, 알고리즘, 결과 또는 주요 UX를 변경할 때는 `analytics.js`의 버전도 올리세요.

```js
const GAME_VERSION = "1.1.0";
```

버전을 변경해야 새 데이터가 이전 버전과 구분됩니다.

### 3. 화면과 선택지

- Q1 이후 선택지는 기존 `.choice` UI를 유지합니다.
- 모바일 화면에서 설명 영역만 스크롤되고 선택지와 하단 탐색 버튼은 보이도록 확인합니다.
- 장면을 추가하면 `scene()`과 `renderRestoredState()` 양쪽에 복원 처리를 추가합니다.
- `이전`, `처음`, `선택` 버튼의 상태 복원이 깨지지 않는지 확인합니다.

### 4. 결과와 공유

- 결과 직역이 단독·공동·전체 균등 상황에서 정확히 표시되는지 확인합니다.
- `1111`과 같은 전체 균등 결과는 분석에서 `all`로 저장되어야 합니다.
- 결과 화면 문구를 바꾸면 결과 복사, 공유 설명과 공유 이미지의 일관성도 함께 확인합니다.
- Kakao 공유 URL과 GitHub Pages 실제 주소가 일치해야 합니다.

### 5. 익명 분석

- `analytics.js`의 `WEB_APP_URL`을 삭제하거나 공개 전 테스트 주소로 바꾸지 마세요.
- 이벤트 오류가 게임 진행을 막지 않는 fail-safe 구조를 유지합니다.
- 새로운 수집 항목을 추가할 때는 개인정보가 포함되지 않는지 먼저 검토합니다.
- Apps Script의 Sheet 열 순서를 임의로 바꾸지 마세요.

### 6. 문구와 안전 안내

- 네 직역 중 특정 직역을 우월하거나 부차적인 역할로 표현하지 않습니다.
- 의료적 진단이나 치료 효과를 단정하는 표현을 사용하지 않습니다.
- 위기 안내, 109·112 및 전문기관 이용 안내를 삭제하지 않습니다.
- 기획·제작·감수·배포 크레딧과 링크를 유지합니다.

## 유지보수 원칙

새 기능은 기존 질문·점수 계산·결과 알고리즘과 분리하여 구현합니다. 분석 이벤트나 저장 항목을 추가할 때도 `analytics.js`와 Apps Script의 인터페이스를 통해 확장하고, 게임이 분석 시스템의 장애에 영향을 받지 않도록 유지합니다.
